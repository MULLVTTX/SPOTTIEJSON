# SPOTTIEJSON

Sanitized Spotify streaming history, published as smaller plain-text JSON files for easier browsing and use with the GitHub app.

Start at the [dataset index](./spotify-history/README.md) for file links, record counts, privacy details, and guidance for ChatGPT. The original sanitized compressed export is also available on [GitHub Pages](https://mullvttx.github.io/SPOTTIEJSON/Spotify_Streaming_History_Public.json.gz).
